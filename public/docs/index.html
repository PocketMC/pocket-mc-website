3. Architecture Topology & Component Overview

High-performance separation of concerns between client UI, runtime supervision, and secure cloud relays.
PocketMC Architectural Ecosystem
The PocketMC ecosystem separates client-side local runtime execution from third-party provisioning APIs to ensure maximum security, zero credential exposure in open-source binaries, and high-performance server orchestration.
1. Native Desktop Client
WPF application on .NET 8 Desktop Runtime. Houses the Mica visual presentation layer, process lifecycle supervisors, JRE/PHP binary down loaders, and local DPAPI hardware key vault.
2. Local Loopback Daemon
Internal high-speed HTTP daemon bound strictly to 127.0.0.1. Provides the local REST API and stdio MCP execution bridge for automated scripts and AI agents.
3. Stateless Partner Proxy
Stateless ASP.NET Core proxy deployed on Render. Secures Playit partner claim flows and OAuth token exchange so open-source clients never store developer secrets.
