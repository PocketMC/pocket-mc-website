How to Submit Useful Bug Reports

To help maintainers resolve bugs rapidly, please include the following diagnostic details when opening an issue:

  1. PocketMC Version: The exact release tag (e.g. 1.9.3).
  2. Operating System: Windows 10, Windows 11, Linux distribution, or macOS version.
  3. Server Engine & Version: e.g., PaperMC 1.21.1, Fabric 1.20.4, or Bedrock BDS.
  4. Sanitized Logs: Export the diagnostic bundle from App Settings (passwords and IPs are automatically redacted).
