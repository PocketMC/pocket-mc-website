Submitting Effective Bug Reports

Including these diagnostic parameters helps contributors reproduce and fix issues quickly.

Parameter 01
Release Tag
Exact release version (e.g. v1.9.3) found on the App Settings page or release footer.
Parameter 02
Operating System
Your host OS and build: Windows 10/11, Ubuntu, Arch Linux, or macOS version and architecture (x64/ARM64).
Parameter 03
Server Software
Engine and version being run (e.g. PaperMC 1.21.1, Fabric 1.20.4, NeoForge, or Bedrock BDS).
Parameter 04
Sanitized Logs
Export the diagnostic bundle from App Settings; passwords and personal IP addresses are automatically redacted.
