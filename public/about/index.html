Empowering Minecraft server self-hosting.

PocketMC is a community-driven, 100% free, and open-source local Minecraft server manager. Engineered to eliminate terminal complexity, PocketMC automates runtime dependencies, zero-port-forwarding public tunnels, and multi-cloud backups while safeguarding your privacy.

MIT Licensed Local-First Architecture Windows · Linux · macOS Zero Cloud Lock-In

Our Core Principles

Designed from first principles to prioritize user autonomy and security.

Principle 01

Local-First & Private

All server worlds, config files, and console logs remain strictly on your local hardware. We run no cloud database lock-ins and never gate your game saves behind subscriptions.

Principle 02

Zero Technical Friction

No router logins, CGNAT workarounds, or manual Java PATH headaches. PocketMC auto-provisions exact Adoptium Java and PHP runtimes and connects Playit.gg/Cloudflare tunnels in seconds.

Principle 03

100% Free & Open Source

Distributed under the permissive MIT License. Zero paywalls, zero artificial player slot limits, zero advertising bloat, and zero telemetry monetization.

Architecture & Engineering

Production-grade desktop architecture designed with Clean Architecture principles.

Runtime Sandboxing
Isolates Adoptium JRE packages (Java 8, 11, 17, 21, 25) dynamically mapped per server version. Also manages PHP 8.2 binaries out-of-the-box for PocketMine-MP instances.
Native Encryption
Sensitive secrets (OAuth tokens, API keys) are encrypted using Windows DPAPI on Windows, Linux Secret Service on Linux, and Apple Keychain on macOS.
RCON Backup Safety
Executes authenticated RCON sequences (save-off & save-all flush) before archiving to prevent database corruption, followed by auto-sync to Google Drive, OneDrive, and Dropbox.
Client Platforms
Engineered in .NET 8 with native Windows Presentation Foundation (WPF) for Windows and Avalonia UI for cross-platform Linux and macOS desktop parity.
