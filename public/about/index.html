About PocketMC

PocketMC is a community-driven, free, and open-source local Minecraft server management platform. Born from the belief that running your own multiplayer Minecraft server should be as effortless as launching singleplayer, PocketMC automates Java runtimes, network tunneling, mod management, and cloud backups while safeguarding user privacy.

Our Core Principles

1. Local-First & Private

All server worlds, configurations, and logs remain strictly on your local machine. We do not operate proprietary cloud databases or lock your game saves behind subscriptions.

2. Zero Technical Friction

No router logins, CGNAT workarounds, or manual Java PATH configurations. PocketMC provisions Adoptium Java runtimes and Playit.gg tunnels in seconds automatically.

3. 100% Free & Open Source

Distributed under the permissive MIT License. Zero paywalls, zero artificial player slot limitations, and zero telemetry monetization.

Architecture & Engineering

PocketMC is engineered using modern .NET 8, utilizing Windows Presentation Foundation (WPF) for high-performance desktop integration on Windows and Avalonia UI for cross-platform Linux and macOS deployments.

  • Runtime Isolation: Uses per-instance sandboxing to run Eclipse Adoptium Java 8, 11, 17, 21, and 25 runtimes alongside PHP 8.2 for PocketMine-MP.
  • Native Security Encryption: Sensitive credentials (such as API keys and backup OAuth tokens) are stored using platform-native security APIs: Windows DPAPI on Windows, Linux Secret Service on Linux, and macOS Keychain on Apple macOS.
  • Graceful Process Management: Uses authenticated RCON commands to signal servers with save-off and save-all flush before backups to guarantee world file integrity.
