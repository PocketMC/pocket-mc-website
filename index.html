Core Capabilities & Key Features

Automated Adoptium JRE Provisioning

Eliminates Java version conflicts. PocketMC detects your server requirement and automatically installs and manages isolated Eclipse Adoptium Java 8, 11, 17, 21, and 25 runtimes locally without polluting system variables.

Zero-Port-Forwarding Playit.gg Tunnels

No router logins, CGNAT bypass issues, or firewall reconfigurations required. An integrated Playit.gg wizard provisions secure encrypted tunnels with custom shareable hostnames for friends.

Modrinth & CurseForge Marketplaces

Search, browse, and install thousands of Minecraft mods, plugins, datapacks, and Bedrock add-ons directly within the PocketMC interface with one-click dependency resolution.

OAuth Cloud & Local Backups

Automated backup engine holds RCON saves, skips lock files, performs SHA-256 integrity verification, and replicates world archives directly to Google Drive, Dropbox, or OneDrive.

Mobile Remote Control Dashboard

Monitor CPU/RAM metrics, read real-time sanitized console logs, execute server commands, and control server instances from your phone via quick QR-code pairing or Discord bot commands.

GeyserMC Java & Bedrock Crossplay

Built-in Geyser and Floodgate integration allows Bedrock players on iOS, Android, Xbox, PlayStation, and Nintendo Switch to join your local Java server seamlessly.

Frequently Asked Questions

How do my friends join the server, and how can I manage it remotely?
PocketMC supports remote access for both gaming and administration. For players joining Minecraft, use the built-in Playit.gg tunnel agent, routing local ports to public shareable addresses without router configuration. For remote administration, enable the Remote Control Dashboard to access a secure, password-protected web panel accessible over LAN, Playit HTTPS, or Cloudflare Quick Tunnels.
Does PocketMC require Windows administrator privileges?
No. PocketMC runs entirely in user-space and installs per-user. It downloads Adoptium JRE runtimes locally and maps isolated instance directories without requiring administrative elevation or polluting your Windows system environment variables.
Do I need to install Java or PHP on my computer beforehand?
No. PocketMC manages all runtimes locally. It automatically provisions the correct Adoptium Java version (8, 11, 17, 21, or 25) based on your Minecraft server type and version. For Bedrock PocketMine-MP servers, it installs an app-local, optimized PHP 8.2 runtime automatically.
How does Playit.gg tunneling work? Do I need to configure port forwarding?
Zero router configuration is required. PocketMC features an integrated Playit.gg agent setup wizard. Once paired, it automatically provisions background agent processes, maps local ports (Java, Bedrock, Geyser, PocketMine, and Simple Voice Chat), and creates public addresses for your players.
Can Bedrock (console/mobile) players join a Java server managed by PocketMC?
Yes. PocketMC supports automatic GeyserMC and Floodgate setup during server creation for supported Java server loaders. It also scans your mod/plugin folders to verify cross-play status and displays active cross-play indicators on your dashboard.
Where are my server files stored and how secure are the backups?
All server files are stored 100% locally on your machine in the root folder you select. PocketMC's built-in backup engine locks active servers using RCON save-holding before copying, skips lock files like session.lock to avoid conflicts, and offers secure, OAuth-based replication directly to Google Drive, Dropbox, and OneDrive.
Can I import existing worlds or custom Bedrock add-ons?
Yes. You can import existing world folders directly, place custom JAR files, or ingest Bedrock .mcpack, .mcaddon, and world .zip files. PocketMC automatically parses manifests, maps dependency requirements, and registers packs.
Are my server logs shared with third-party AI systems?
Only if you explicitly configure an AI provider and request a log summary. PocketMC pre-processes and sanitizes all logs locally (automatically scrubbing IP addresses, emails, and personal info) before sending them to your provider of choice (Google Gemini, OpenAI, Claude, Mistral, Groq, or local Ollama).
Will my server stay online if my Windows PC goes to sleep?
PocketMC includes native Windows power integration that automatically prevents your PC from entering sleep mode while any Minecraft server instance is actively running. Once all servers are stopped, standard Windows power saving behaviors resume.
